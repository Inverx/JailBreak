**大模型越狱与提示注入研究资料库**

一个围绕大语言模型（LLM）安全边界、Jailbreak（越狱）与 Prompt Injection（提示注入）整理的研究资料库。

项目主要收集社区公开资料、模型相关实验记录及技术分析，关注大模型安全对齐机制、提示注入攻击面、攻防技术演进与安全防御体系。

## 内容概览

### 1. 技术分析

[大模型越狱与提示注入技术全景分析](./大模型越狱与提示注入技术全景分析.md)

- Jailbreak 技术演进与分类

- 多轮对话与上下文安全

- 大模型安全对齐与防御机制
- 自动化安全评估框架
- 工业级安全护栏与防御体系

## 研究方向

项目关注以下几个方向：

| 方向 | 研究内容 |
| --- | --- |
| Jailbreak | 越狱技术分类、演进及模型行为分析 |
| Prompt Injection | 直接与间接提示注入、多模态攻击面 |
| LLM Security | 模型安全边界与安全对齐机制 |
| Agent Security | 工具调用、上下文隔离与权限边界 |
| Defensive Research | 安全护栏、输入净化与风险评估 |

## 使用说明

本仓库主要用于技术研究、资料归档与安全分析，不是一个可直接运行的攻击工具或自动化越狱平台。

部分资料来源于互联网社区，未经统一验证，不保证其准确性、时效性或对特定模型的有效性。模型版本、服务策略和安全机制发生变化后，相关记录可能失效。
